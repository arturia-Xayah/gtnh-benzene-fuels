# LuV / ZPM 苯转子选型

版本：GTNH 2.9.0-RC-2 / GT5 5.09.54.205。后台读取211种有叶片候选材料，并交叉核对实际组装机配方；182种材料确有涡轮转子输出配方。阶段门槛另查配方和上游材料，不以转子挖掘等级代替解锁等级。

均按新式特大燃气轮机、12个同材质同尺寸转子、紧装、最佳整数流量、满维护和足够动力仓计算。不含转子成本、启动过程、线路损耗和生产耗电。

巨型精金、巨型灵宝和巨型极不稳定硅岩会触发该版本ZPM苯的高热值限功率分支，不作为ZPM方案。巨型铿铀安装在普通大型燃气轮机中，紧装最佳流量向下取整为0；因此推荐特大机。

单台轮机供油超过表中最佳流量会降低效率。供应更多燃料时，应复制相同模块并分别限流，或者接受松装/超载效率折损。输出动力仓总承载能力应达到表中功率。

配方确认排除了仅有材料属性/叶片条目、没有实际涡轮组装配方的光素、磁共振材料、阿瑟锡等候选。运行时数据见 turbine-candidates-runtime.json。
